## 自动化测试

`python -B -m unittest discover -s tests -v` 共7项通过，覆盖：

- 不同安装独立生成密钥，正常重启保留已有密钥。
- 拒绝非学校域名、通配符、配置注入和无效端口。
- 校内出站默认只允许明确目标，兜底拒绝，不依赖Cookie或测试证书。
- 下载鉴权、错误令牌404、无缓存响应及分流规则不包含凭据。
- WebSocket升级时保留已跟随HTTP头部发送的二进制帧，双向转发不丢数据。
- 归档文件不能向工具目录外写文件。
- 固定Tunnel令牌通过文件读取，不能指向private目录外，命令参数不包含令牌内容。
